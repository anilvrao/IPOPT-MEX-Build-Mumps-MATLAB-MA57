# Notice

This repository packages build materials and precompiled MATLAB MEX files for a
GPOPS-II-compatible IPOPT interface.

The MATLAB MA57 runtime is not included here as a separate library.  The macOS
and Windows bridge code is designed to use the MA57 runtime supplied by the
user's installed MATLAB distribution.

Large third-party source trees are intentionally not included.  Users who rebuild
the MEX files should obtain third-party packages, compilers, and MATLAB through
their respective official distribution channels and comply with the corresponding
license terms.
